# Melt Me by Jasmine

A modern dessert business website built to showcase products, strengthen brand identity, and create a polished customer experience through responsive front-end development.

## Live Demo

https://meltmebyjasmine.netlify.app/

## Project Overview

This project was designed as a real-world small business website focused on helping a dessert brand attract customers through clean visuals, strong branding, and intuitive navigation.

## Features

- Fully responsive design
- Mobile-friendly layout
- Product showcase sections
- Branded visual styling
- Customer-focused user flow
- Clear call-to-action sections
- Professional business presentation
