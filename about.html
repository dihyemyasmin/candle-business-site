About Melt Me

Candles made with intention, care, and love.

Our Story

Melt Me was created from a genuine love for candles and the quiet moments they create. This website is part of a template from Templates Jungle, adapted for a portfolio project.

The original template showcases a clean and modern design. All images, content, and layout are placeholders meant for learning and demonstration purposes.

This project highlights basic web development skills: HTML structure, CSS styling, and simple layout design. It is intended to show coding ability rather than a live business.
